# 总体设计报告评审 PPT — 设计约定

## 全局视觉约定（全篇不换）

- 画布 1280×720；padding 上下 60 / 左右 60；内容区 1160×600（x 60–1220，y 60–660）。
- 配色沿用参考稿《需求阶段评审》：
  | 槽位 | Hex | 用途 |
  |---|---|---|
  | 主色 | `#14563F` | 页面主标题、编号、强调 |
  | 正文色 | `#1C2A24` | 正文、表格文字 |
  | 辅助色 | `#5A6B61` | 副标题、注释、眉标 |
  | 浅底 | `#F4F8F5` | 卡片底、结论条 |
  | 分隔线 | `#CFD9D2` | 1px 贯通细线、表格线 |
  | 底色 | `#FFFFFF` | 页面背景 |
- 字体：Microsoft YaHei 全篇统一。字号阶梯：封面主标 56 / 副标 26 / 信息 16；页主标 32 / 副标 16；卡小标 22；正文 18；表格 16；注释与眉标 14；巨型数字 64。
- 视觉母题：每页固定「左上主标题 + 右侧副标题 + 右上眉标 `FTDMS · 总体设计报告`」，标题下 1px 贯通细线（y≈104）；内容区以细线/留白分区，底部按需放一条浅底结论条。封面、目录、参考资料、评价页沿用同一标题栏但允许自定义主体。
- 配图：全篇只使用项目自有 logo，无外部图片、无生成图，避免素材与水印风险；其余内容以文字卡片、编号列表、表格与结构块承载。
- Logo 母题：内页右上角固定 36×36 方形图标角标，与眉标 `FTDMS · 总体设计报告` 同行；封面顶部使用完整横幅 logo（320×88）。全篇位置一致，不逐页漂移。

## 页面节奏

全篇 18 页：封面 1、目录 1、正文 14、参考资料 1、分工评价 1。Hero 页为封面、系统总体架构页、成员评价页；其余为 Supporting 高密度信息页，页间以「三卡 / 两栏 / 表格式 / 流程链」交替避免连续同版式。不生成章节扉页（各章仅 1 页，按设计原则 §1.10 省略）。
