## 实现与关键契约

- [HTTP 层](../../frontend/src/lib/http.js)：默认基址 `/api/v1`，同时检查 HTTP 状态与业务 `code`；不把 HTTP200 业务失败误判为保存成功。保留可读错误、状态码、业务码及 traceId。
- [远程仓储](../../frontend/src/lib/remoteRepository.js)：JWT 登录/注册后自动登录/登出，标签页会话存储；目录分页与有界详情并发；ID、英文餐次/状态、目标字段和扁平训练组 DTO 转换。
- [共享状态](../../frontend/src/lib/useData.js)：显式业务操作、写入后回读、旧请求/旧账户保护；真实与演示严格分离。已确认写入但回读失败时提示刷新确认，不重复创建；不发布未保存的草稿。
- 六类页面使用真实账户、目标、计划、训练记录、食物与营养快照、体重及服务端统计。7/30 日与自定义范围保留缺失值，不自动补零。
- 训练完成率把服务端 0–1 转为显示百分比，分母排除取消计划。区间体重均值按服务端有效记录点计算，单独显示服务端七日平均及有效天数。
- 多日读取不逐日请求饮食明细；统计直接调用服务端统计 API。当日饮食使用服务端汇总/快照；历史详情完整回读。
- 「记录并完成」使用两个接口：先创建真实记录，再变更计划状态；第二步失败保留真实记录，关闭已保存草稿，只允许用户重试标记完成，不伪称原子事务。
- 前端开发与构建预览均支持 `/api` 同源代理；生产静态部署仍需另配 HTTPS 反向代理，不把 Vite 配置误当成生产代理。

## 本次发现并修复的问题

| 问题 | 修复与验证 |
| --- | --- |
| 前端全部使用本地模拟，与真实 DTO 不兼容 | 增加远程仓储、显式异步保存、真实 JWT 和数据回读；浏览器闭环通过 |
| HTTP200 业务错误可能被当成功 | 统一检查 `code`，保留草稿；真实浏览器故障注入验证 |
| 饮食改克重读取最新食物营养，污染历史快照 | 后端按原记录快照/克重比例换算，保留来源；修改食物库后回归通过 |
| 管理员禁用账户后旧 JWT 仍可访问 | 每请求核对当前账户 ACTIVE/role，旧 JWT 返回未授权；集成测试通过 |
| 生日清空被 Bean Validation 拦截 | 修改资料的 nickname/birthDate 支持空字符串清除；浏览器创建/清空生日通过 |
| 无饮食记录日的 kcal 被序列化省略 | 明确返回 `null`，前端也防御性保留缺失；测试通过 |
| 未知 API 路径被归类内部错误 | 统一为资源/接口不存在业务码；测试通过 |
| 实际训练补录未限制过去 365 日 | 与记录补录窗口统一；边界测试通过 |
| JDK23+ 不自动发现 Lombok processor | 显式处理器路径并升级兼容 JDK25 的 Lombok，保留 target17；打包通过 |
| 旧登出响应可能清除新登录令牌 | 登出同步清旧会话，捕获旧 token 发请求，不在晚到 finally 清新会话；成功/401 两种竞态回归通过 |
| 编辑计划标题可能静默清空已有备注 | 保留已载入的原 note 一起提交，避免整单替换丢失隐藏字段 |

1. 注册自动登录 → 食物详情/150g 录入/200g 更新/刷新 → 同日体重 upsert → 创建计划/记录并完成 → 统计 → 资料和生日清空/目标 → 刷新 → 登出令牌失效 → 新账号无法读取/删除他人记录 → 原账号重新登录并删除本人饮食/体重。

5. **对饮食写接口故障注入** HTTP200 非零业务码、网络失败：保留草稿、不写本地模拟库、恢复网络后可保存。

## 仍需后续验收的边界

- MySQL 8.4 上重跑持久化、事务、日期与跨账号用例；本次没有安装或连接 MySQL。
- 正式反向代理、HTTPS/CORS、网络延迟/断网、Android 真机与 APK。当前预览仅绑定回环地址，不能直接用于手机访问。
- AI 授权/报告、管理员界面、改密界面；本次没有任何模型调用或 AI 授权收集。
- 训练记录/完成状态是两个非原子请求；网络超时无法证明写入未生效，应先刷新确认再重试。服务端暂未引入写入幂等键。
- `TokenBlacklist` 仍为内存结构，服务端重启后登出撤销状态不持久；正式部署需持久撤销或其他会话策略。本次未扩展数据库表。
- 原饮食快照只有两位小数，按比例调整仍存在该存储精度边界；后端未暴露完整历史食物名称/生熟来源快照，界面已避免伪称完整来源快照。
- 食物/动作目录目前全量分页获取，适合课程小型数据；大库需远程搜索及按需加载。记录查询最多366天，不代表无限历史。
- 同源脚本仍可读取标签页令牌；多标签页并发编辑不提供冲突合并，尚未进行生产安全加固。
