# 循练 · FTDMS 前端第一版

Vue 3 + Vue Router + Vite + Axios + ECharts，移动优先，适配 320px 及以上屏幕。仅新增前端与说明，保留第一阶段原型，不修改后端或数据库。

## 运行

要求 Node.js >= 22.12.0（验证版本 24.21.0），pnpm 11.28.5。

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
# http://127.0.0.1:5173
pnpm build
pnpm preview
```

生产部署发布 `dist`；使用 hash 路由，不需要服务端配置 SPA 路由回退。首次依赖安装需要网络；页面不加载外部字体或图片。使用 localhost / 127.0.0.1 或 HTTPS，以支持 WebCrypto。此处 Web 构建不生成 APK。

## 演示与隐私边界

- 点击「体验示例数据」，或使用 `demo / demo1234`。首次生成相对当前业务日期的样例，故意保留缺失日；后续保留编辑结果。
- 注册创建独立本地账户，初始记录为空，附带明确的示例默认目标。用户名 3–32 位（界面限制），演示密码 8–128 位；不要使用真实密码。
- **这是本地模拟，不是真实服务或身份认证**。所有数据保存在当前浏览器的 `localStorage`，没有发送后端；不同浏览器/设备不共享。口令使用随机盐和 PBKDF2-SHA256（210000 轮）派生，不保存明文；健康记录未加密，存储可被用户或同源脚本篡改，不构成安全边界。
- 退出只移除本地会话，保留账户记录。清除本站浏览器数据会移除所有演示数据。不要录入真实口令或敏感健康数据。
- 存储失败不发布新状态、不清空草稿；损坏存储报错，不静默重建。多标签页没有协同编辑/冲突合并保证，演示时请使用单标签页。
- 食物均为「演示估算」并标注生熟与来源；不是权威营养数据库，不用于医疗或营养决策。

## 业务口径

- 业务日期使用 `Asia/Shanghai`，按自然日补录；没有从 UTC 截断「今日」。
- 单项营养 = 每 100g 营养 × 克重 ÷ 100；不在计算中四舍五入，显示 kcal 整数、营养素一位小数。
- `diet.snapshot` 是该项**实际摄入量**，不是每 100g；保存名称、来源、生熟状态。修改克重按原快照比例换算，不读取更新后的食物库营养值。
- 计划目标不是实际训练；关联计划只复制动作身份，不填实际重量/次数。可以「仅标记完成」，但不会伪造实际组记录；「记录并完成」需要填写实际值。
- 编辑/取消不删除或重写实际历史。完成率 = 完成计划 / 未取消计划；无计划显示暂无计划，临时训练单独计数。
- 同账户同日体重只有一条，重复保存为更新。统计缺失值为 `null`，不补零；折线 `connectNulls: false`。均值仅统计有效天数并标注天数。
- 统计页七日均值以区间结束日为锚点，虚线是所选区间均值；最多 366 个自然日。

## 代码分层与后续联调

```text
src/App.vue                 登录与应用框架
src/views/                  今日、训练、饮食、体重、统计、我的
src/components/TrendChart.vue ECharts 生命周期、resize、dispose、无障碍表格
src/lib/domain.js           日期/营养/统计纯函数（模拟口径参考）
src/lib/repository.js       分账户本地持久化与演示样例
src/lib/useData.js          共享响应式状态、保存成功才更新、busy/error
src/lib/http.js             预留 Axios 客户端（当前页面未使用）
```

Axios 默认基址 `/api`（可用 `VITE_API_BASE_URL` 配置），开发代理指向 `http://localhost:8080`；超时和 401 转为可读错误，不静默转回模拟数据。配置基址**不会自动把页面切换为真实模式**。不要在 `VITE_*` 放密钥，这些值会进入浏览器构建。

下一步必须与后端确认 URL、DTO、分页/搜索、错误码、认证与过期机制、CORS/HTTPS、Asia/Shanghai 归属。当前前端对象只是本地演示契约，**不是已确认后端接口**。请新增远程仓储适配器并将调用改为异步加载、服务端保存后重新查询，再移除演示标识；禁止混用本地/远端数据或失败时静默 fallback。

权限、营养/统计权威计算和归属校验必须由后端完成；前端路由与本地账户不能替代授权。改接后端时应保持本版交互口径，并补充服务端授权、失败重试、跨账号越权及移动网络测试。

## 自动测试

```sh
pnpm test
pnpm exec playwright install chromium
pnpm test:e2e
# Windows 已安装 Edge 时可免下载：
# PowerShell: $env:PLAYWRIGHT_CHANNEL='msedge'; pnpm test:e2e
```

Playwright 自行启动并关闭 `127.0.0.1:4179` 临时测试服务；端口占用时明确失败，不复用未知服务。截图/追踪在 `test-results`，未提交到 Git。

本次验证：Node 24.21.0、pnpm 11.28.5、Windows Edge headless；`vite build` 通过；17 项单元/状态测试、3 项浏览器用例通过。浏览器覆盖 1280/375/320px 全页面无横向溢出、无未捕获异常、注册、饮食录入修改、同日体重更新、计划与实际打卡、资料/目标历史、刷新持久化、切换账户隔离、写入失败保留原数据和草稿。

在禁止子进程的沙箱内，Node 测试可使用：

```sh
node --test --test-isolation=none tests/domain.test.js tests/repository.test.js
```

构建工具和浏览器测试仍需要允许启动子进程。上述结果不等于 Android 真机、真实后端或所有浏览器验收。
