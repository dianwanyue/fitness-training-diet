# 循练 · FTDMS 前后端联调版

Vue 3 + Vue Router + Vite + Axios + ECharts，移动优先，适配 320px 及以上屏幕。默认连接真实 Spring Boot 服务；保留独立本地演示，不会在服务失败时自动 fallback。

## 启动真实模式

要求 JDK 17+、Maven、Node.js >=22.12.0、pnpm 11.28.5。先启动后端，再启动前端（两个终端）：

```sh
# 终端一：H2 文件库，无需先安装 MySQL
cd backend
mvn spring-boot:run -Dspring-boot.run.profiles=h2

# 终端二：从仓库根目录开始
cd frontend
pnpm install --frozen-lockfile
pnpm dev
# http://127.0.0.1:5173
```

PowerShell 如不能正确解析 Maven 属性，可写 `mvn spring-boot:run '-Dspring-boot.run.profiles=h2'`。后端默认 8080，前端默认 5173。首页选择「真实后端模式」注册或登录：用户名 4–20 位字母、数字、下划线；注册密码 8–32 位可见字符且包含字母与数字。注册后自动登录；新账户没有伪造的健康记录或默认服务端目标，请在「我的」中设置目标。

正式 MySQL 启动方式见 [后端说明](../backend/README.md)。不要同时启动两个进程占用 8080，H2 文件数据库也不能被两个后端同时打开。

### API 配置与部署

可将 [.env.example](.env.example) 复制为 `.env.local`，修改后重启 Vite：

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | `/api/v1` | Axios 完整接口前缀，**必须含 `/v1`** |
| `FTDMS_API_TARGET` | `http://127.0.0.1:8080` | Vite dev/preview 的 `/api` 代理目标，**不含 `/api/v1`**；用终端环境变量设置 |

`FTDMS_API_TARGET` 由 Vite 配置读取系统环境变量；例如 PowerShell：`$env:FTDMS_API_TARGET='http://127.0.0.1:8081'; pnpm dev`。不要将真实密钥放进 `VITE_*`，这些值会进入浏览器构建。

```sh
pnpm build
pnpm preview
```

`preview` 也代理 `/api`，可本地验证构建产物。正式部署发布 `dist`，使用同源 HTTPS 反向代理把 `/api/` 原样转发给后端（不移除 `/api/v1`）。Vite 代理不会随静态文件部署；不配置正式反向代理会导致 API 404。若用跨域绝对 API 地址，需部署方另行设置后端 CORS 与 HTTPS，当前开发默认使用同源代理。前端使用 hash 路由。Web 构建不生成 APK。

## 已接入页面

| 页面 | 真实接口与能力 |
| --- | --- |
| 登录/注册 | 后端注册、登录、JWT、过期/401 处理、服务端登出 |
| 今日 | 所选日期计划、营养快照、当日目标/体重、七日有效记录统计 |
| 训练 | 服务端动作库、计划增改/取消/完成、多动作多组实际记录、临时训练、近 366 日历史 |
| 饮食 | 服务端食物库及完整营养来源、餐次录入、克重修改、删除、服务端快照回读 |
| 体重 | 按日期 upsert、删除、近 366 日记录、30 日服务端趋势 |
| 统计 | 7/30 日及自定义范围、完成率、摄入/体重趋势、有效天数、可展开图表数据 |
| 我的 | 资料修改/出生日期清除、目标设置与历史、退出登录 |

保存后重新查询服务器，再发布页面数据；失败保留草稿。已确认写入但回读失败时明确提示「已保存，请刷新确认，不要重复提交」。顶部「刷新服务数据」用于主动重新连接/加载。

**未交付**：管理员页面、改密页面、AI 授权/报告、Capacitor/Android APK、Android 真机与正式部署验收。这些不应被本次 Web 核心联调结果代替。

## 数据、会话与业务边界

- 真实模式 JWT 放在当前标签页 `sessionStorage`，不保存密码；健康记录仅作内存展示，不写入本地演示库。刷新可恢复标签页会话，关闭标签页后需要重新登录。会话存储仍可能被同源脚本读取，不是加密保险箱，请在可信设备及 HTTPS 环境使用。
- API 对 HTTP 状态和 `{code,message,data,traceId}` 同时检查，HTTP 200 不一定成功。401/1002 清会话和私有页面；403/业务错误/网络错误明确提示，不填入演示数据。
- 所有 ID、餐次、状态、DTO 的转换集中在远程仓储；权限、营养快照及权威统计由后端处理，前端不提交 `userId` 或营养计算结果。
- 日期口径为 `Asia/Shanghai`，查询区间最多 366 天。计划/饮食/体重/目标写入日期限制为今天前 365 天至未来 7 天；实际训练不能在未来。目标列表查询近 358 天至未来 7 天，并补入当前生效目标；不冒充无限历史。
- 营养预览是每 100 g × 克重 ÷ 100；真正保存的是服务端返回的实际摄入快照。修改克重沿用原快照比例，不读取变更后的食物库。后端未提供饮食历史来源/生熟快照字段，界面不会把当前食物来源伪称为历史来源。
- 计划和实际训练独立：「仅标记完成」不制造实际记录；「记录并完成」先保存记录再完成计划，是两个接口而非一个原子事务。如果第二步失败，关闭已保存草稿并只提示重试标记完成，避免重复记录。
- 完成率 = 已完成计划 / 未取消计划；无计划为 `null`。缺失摄入/体重为 `null`，不补零；平均值标注有效天数。七日均值窗口为所选区间结束日向前最多 7 天；区间体重均值是按后端有效记录点计算的展示指标，不伪称后端额外指标。
- 食物与动作分页完整加载；食物详情并发数有界。本版适用于课程小型公共库；大规模目录可进一步改为远程搜索和按需详情。

## 独立演示模式

登录页可选「本地演示模式」，或点击「体验示例数据」进入 `demo / demo1234`。该模式只使用浏览器 `localStorage`，不请求后端；保留相对当前日期的样例和缺失日。可创建独立本地账户，但不是服务器认证或权限隔离验证。PBKDF2 不保存明文演示密码，健康记录未加密且可被同源脚本篡改，请勿输入真实敏感数据。

模式选择保留在标签页会话中，界面始终标明当前模式；演示账号不能作为真实后端身份使用，真实服务失败也不会切换模式。退出仅清会话，不删除记录；清除浏览器站点数据会删除本地演示库，不会删除服务端记录。

## 代码分层

```text
src/App.vue                   模式选择、登录、应用框架与全局刷新
src/views/                    六类业务页面，显式异步业务操作
src/lib/http.js               Axios、响应封套检查、业务/网络错误
src/lib/remoteRepository.js    JWT、真实 API、DTO 双向转换、服务端统计
src/lib/useData.js             共享状态、远程/演示隔离、保存后回读、旧请求保护
src/lib/repository.js          独立本地演示库（无远程 fallback）
src/lib/domain.js              日期/营养/演示统计纯函数
src/components/TrendChart.vue 图表生命周期、无障碍文本数据表
```

实际 API 契约见 [后端联调契约](../backend/API_CONTRACT.md)。

## 自动测试

```sh
pnpm test
pnpm build
# 无后端也可运行原有演示回归；真实后端套件默认跳过
pnpm test:e2e
# 先启动真实后端，再运行；不会跳过真实套件
pnpm test:integration
```

浏览器默认 Chromium，可 `pnpm exec playwright install chromium`；Windows 已安装 Edge 时可免下载：

```powershell
$env:PLAYWRIGHT_CHANNEL='msedge'
pnpm test:e2e
pnpm test:integration
```

Playwright 默认自动启动并关闭 `127.0.0.1:4179` 临时 Vite 服务；端口占用时失败，不复用未知进程。若要验证已构建的预览，可先启动 `pnpm preview --port 5173 --strictPort`，再显式设置 `$env:FTDMS_E2E_URL='http://127.0.0.1:5173'` 后运行同样测试；此时测试不另启服务。真实套件使用 `/api/v1` 代理请求真正的 Spring/H2 服务：正常流程不 mock；错误用例另行故障注入 HTTP200 业务失败、网络断开。测试会创建 `e2e*` 账户和记录，请只指向隔离开发/验收库，不能对真实用户生产库运行。报告/截图/trace 位于被 Git 忽略的 `test-results`。

验证结果与已知限制见 [本次联调记录](../docs/联调/2026-11-04_前后端联调记录.md)。本次本地 H2 + Edge 验证不等于 MySQL、所有浏览器、Android 真机或公网部署验收。
